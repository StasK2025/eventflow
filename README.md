# 🎟️ EventFlow — менеджер участников мероприятия

Локальное веб-приложение для учёта гостей мероприятия: импорт списка из CSV, карточки участников, check-in на входе, поиск и фильтры, резервное копирование. Работает офлайн, без сервера и регистрации.

**Задача:** организатору мероприятия нужен простой и надёжный инструмент учёта гостей, который работает прямо в браузере — без установки, аккаунтов и внешних сервисов.

**Результат:** законченное приложение на чистых HTML/CSS/JS с хранением данных в IndexedDB, 23 автотеста «файл → проверка → итог», адаптив под десктоп/планшет/телефон и продуманная обработка ошибок.

---

## ✨ Возможности

- 📥 **Импорт из CSV** — предпросмотр до загрузки, честная статистика: сколько строк в файле, сколько валидных, сколько с ошибками
- 👤 **CRUD участников** — создание, редактирование, архивация и удаление с явным подтверждением
- 🔍 **Поиск, фильтры, сортировка** — мгновенный фильтр по активным участникам, удобная таблица
- ✅ **Check-in на входе** — отметка о приходе доступна только для подтверждённых (`confirmed`) участников
- 💾 **Резервное копирование в JSON** — экспорт и восстановление данных с валидацией бэкапа
- 🛡️ **Валидация на всех уровнях** — единая функция `validateParticipant`: форма, CSV и JSON проходят одни и те же проверки; email уникален

## 🛠️ Стек

| Технология | Роль |
| :--- | :--- |
| HTML / CSS | семантическая разметка, темы (светлая/тёмная/высококонтрастная), адаптив 1440 / 768 / 390, `prefers-reduced-motion` |
| JavaScript (ES6+) | вся логика: интерфейс, валидация, импорт/экспорт |
| IndexedDB | локальное хранилище `eventflow-db` v1: таблицы `participants`, `settings`, `activity` (журнал) |

Без фреймворков, без npm, без сборщиков, без CDN и внешних API — только браузер.

## 🚀 Как запустить

1. Клонируйте репозиторий
2. Откройте `app/index.html` в браузере — можно просто двойным кликом (работает без HTTP-сервера)
3. Для полного сценария: импортируйте `data/participants.csv`, затем попробуйте `data/participants-with-errors.csv` — увидите честную статистику ошибок

## 🧪 Тесты

23 автотеста, сгруппированных в 6 этапов: импорт + UI → форма/CRUD → CSV-выгрузка → поиск/фильтры → экспорт/восстановление → итог. Каждый этап завершается итоговым чек-листом «файл → проверка → итог».

**Ключевые решения:**
- email — обязательное поле с уникальностью по всей базе (ключевое ограничение схемы)
- единая функция `validateParticipant` для формы, CSV и JSON — одна правда для всех входов
- опасные действия (удаление) требуют подтверждения, архивация — мягкая альтернатива удалению
- диалоги импорта показывают предпросмотр до записи данных
